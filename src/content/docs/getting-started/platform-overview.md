AI Workforce organizes work around a workspace, its employees, and the sessions and results they create. Different product surfaces support daily use, reusable capability building, and coordinated delivery.

## Daily collaboration

Open **Workspaces** to choose the context in which you want to work. Inside a workspace, select an employee and begin a conversation. A session keeps the conversation and its associated execution history together. The artifact area lets you inspect produced files and, when supported by the execution environment, file changes.

Use the workspace **Task inbox** to review collected or imported requests. An inbox item has its own status, source, and review decisions. A collected item does not become an approved development task simply because it exists.

## Reusable employees

An employee template packages a defined responsibility and the capabilities needed to perform it. Users create workspace employees from published templates. Builders define responsibilities, required inputs, outputs, Skills, and tool requirements before publishing a template for use.

[MCP connections](/build/mcp-integration/) extend what an employee can access. They require the appropriate configuration and authorization; naming a tool in instructions does not grant access to it.

## Automation and delivery

**Automation** organizes repeatable jobs with configured triggers, execution instructions, and result collection. Saving a draft, publishing a definition, enabling a trigger, and manually running a job are separate actions. Inspect the run result before relying on unattended execution.

The **Delivery workbench**, available from Automation, coordinates software work using boards, stages, employees, and linked sessions. Teams can review requirements, clarify missing information, and inspect implementation evidence before proceeding.

## A first end-to-end workflow

1. Choose a workspace and a ready employee.
2. Give it a task with sufficient context and acceptance criteria.
3. Inspect its response, generated files, and supporting evidence.
4. Refine the work or make a review decision.
5. When the task is repeatable, consider an automation with explicit result collection.

If a page or action is unavailable, check workspace permissions and deployment configuration with your administrator. A missing connection or unavailable runtime requires configuration before the employee can use it.
