This lesson publishes the reusable employee package as a template. The workspace then creates or configures an employee instance to use that capability. Follow [Publishing and distribution](/build/publishing/) for the product steps.

Before publishing, validate the package, run the task trials, and identify the version and accepted behavior. After publication, check which version a workspace employee actually uses. Existing instances do not automatically adopt template changes.

A Job has its own draft, publication, and trigger state. Publishing the employee template does not publish or enable that Job. Use [Your first workflow](/getting-started/first-automation/) to inspect a manual run and then enable the intended trigger. This path does not imply a public marketplace.
