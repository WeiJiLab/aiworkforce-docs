Open **Automations → New → Automation task** to create a standalone Job. Define the outcome, choose the employee and inputs, then run it once by hand. Inspect the result before publishing and enabling a trigger. See [Workflow builder](/automate/workflow-builder/#compose-a-job) for the Job steps. If your work starts with a delivery card, follow the [board template walkthrough](/getting-started/first-automation/).
