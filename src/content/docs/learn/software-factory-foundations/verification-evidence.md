Verification compares the result with the agreed acceptance criteria. Evidence lets a reviewer inspect that comparison: the relevant change, tested revision, environment, results, and recorded decision.

## Check the form example

The empty-value message and valid submission both need results. Keep those results connected to the revision being reviewed. A result from an earlier revision can inform investigation, but it does not establish that the current change passed.

Evidence can also show a failure. Preserve the failed check and use it to explain what must be repaired and rechecked.

## Try this judgment

The test record passed yesterday. The employee changed the form code afterward. Is yesterday's pass enough to accept the new change?

The tested and candidate revisions differ. Run the required checks on the new candidate or record precisely what remains unverified. The reviewer needs that distinction to decide.
