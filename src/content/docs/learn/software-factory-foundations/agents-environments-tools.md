An **agent** (often presented as an AI employee in the workspace) performs steps. **Tools** and **MCP** servers expose operations. An **environment** is where execution happens: repositories, devices, and pipelines.

Naming an MCP server or connecting a repository does not by itself grant runtime access. Start from [Agents](/user-guide/ai-employees/), then [Environments](/software-factory/environments/) and [Tools and MCP](/build/mcp-integration/).
