The fastest way to see value is one small Issue on a configured delivery board.

1. Confirm scope and acceptance criteria.
2. Follow implementation on the board.
3. Compare verification evidence to each criterion.
4. Record the review decision.

Do the hands-on path in [Quickstart](/getting-started/quickstart/), then read the worked example [Issue to PR](/recipes/issue-to-pr/).
