In the FDE workbench, open **Interview bots** (访谈机器人). A prompt sets the topic, question structure, tone, and boundaries. Markdown is supported, and the editor can preview it. The prompt is injected into the voice session when the interviewee starts. The interviewee does not see the prompt. Choose a **Voice** (语音音色). Hover preview works after [channel configuration](/fde/channels/) has a voice channel.

**New bot** (新建机器人) asks for a name, a voice, and the prompt. Search matches the bot name. Deleting a bot stops new invites from using it. Existing invites and transcripts stay.

The prompt guides the interview. It does not grant workspace tools, and it does not publish an employee. Send the bot to someone with [Interview invitations](/fde/invites/).
