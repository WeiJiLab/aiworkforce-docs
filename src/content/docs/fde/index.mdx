The FDE workbench is the console surface for FDE users and administrators. It collects fieldwork, iterates an employee package, publishes a template, and runs administrator evaluation. People who install a published employee in a workspace stay in Docs and start from [Agents and AI employees](/user-guide/ai-employees/).

Open **FDE workbench** (FDE 工作台) in the console header. The route is `/fde/`. A signed-in user who is neither an FDE user nor an administrator sees a permission notice. **Channel configuration** (渠道配置) and **Agent tests** (Agent 评估) appear only for administrators.
