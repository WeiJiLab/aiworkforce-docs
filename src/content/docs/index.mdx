AI Workforce helps teams take engineering work from request to review. Software Factory tracks the work on a delivery board, where the team confirms scope, follows implementation, and reviews verification evidence. Workflow Automation starts recurring or event-driven Jobs and can collect requests into the inbox or workbench when configured.

## Review results before acting

Use [evidence and trace](/software-factory/evidence/) to match the code revision to the test environment and results. Record whether the change meets the confirmed acceptance criteria. Follow [review and release](/software-factory/review-release/) for the decisions and checks that come after verification.

[Playbooks](/learn/) show how to write requirements and review feedback. [Integrations and the developer interfaces](/developer/) cover the HTTP API, MCP, and device execution that exist today.

If execution stops or a connection fails, collect the relevant state with [troubleshooting](/resources/troubleshooting/), then use [changelog and support](/resources/releases-support/).
