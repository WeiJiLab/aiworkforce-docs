## Review results before acting

Use [artifacts and evidence](/user-guide/artifacts-evidence/) to see what an employee produced and what supports it. The [Software Factory](/software-factory/overview/) carries confirmed work from intake through execution, verification, evidence, and release. [Human approval](/user-guide/human-approval/) stays on the decisions that change scope or ship a result.

[Playbooks](/learn/) show how to write requirements and review feedback. [Integrations and the developer interfaces](/developer/) cover the HTTP API, MCP, and device execution that exist today.

If execution stops or a connection fails, collect the relevant state with [troubleshooting](/resources/troubleshooting/), then use [changelog and support](/resources/releases-support/).
