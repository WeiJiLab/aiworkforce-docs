To change how a run artifact appears, build a Viewer App that adds a view to the file preview.

Use the HTTP management and Automation routes, inbound webhooks, Automation MCP, or the device executor CLI. To integrate through an inbound webhook, trigger a published Job and query its run for the result. There is no general published SDK package and no ACP or A2A server.
