This page collects the interfaces a builder or platform engineer uses to reach AI Workforce from outside the product UI. Employee authoring stays in [Build AI employees](/build/architecture/). Product connections such as repositories stay in [integrations](/integrations/overview/).

## Choose an interface

| Need                               | Start here                                   |
| ---------------------------------- | -------------------------------------------- |
| Call the platform over HTTP        | [REST API](/developer/api-reference/)        |
| Authenticate a person or a machine | [Authentication](/developer/authentication/) |
| See the deployed schema            | [OpenAPI reference](/integrations/openapi/)  |
| Let an agent call registered Jobs  | [MCP integration](/integrations/mcp/)        |
| Pair an execution computer         | [Device Executor CLI](/integrations/cli/)    |
| Build an application client        | [SDK](/integrations/sdk/)                    |
| Compare the interfaces             | [Interface overview](/developer/cli-sdk/)    |

The [interface overview](/developer/cli-sdk/) compares those choices. There is no supported general Python or TypeScript SDK package. ACP and A2A are not provided in this release. Call the HTTP API or Automation MCP.

## Verify one workflow

1. Agree the outcome, the allowed resources, and the acceptance criteria. Use a [playbook](/learn/) when the work is still unclear.
2. Call only the endpoint or tool your credential is allowed to use. Keep secrets in the caller's secret store.
3. Try a normal call, a missing input, and a denied resource. Read the run id and the error. Do not treat HTTP 202 as a finished business result.
4. When the capability is an employee, validate the package and try it as a workspace instance with the intended runtime.

[Platform architecture](/developer/architecture/) shows how sessions, Jobs, and delivery records differ. [Contributing](/developer/contributing/) is for changes to this documentation and the product source, not for calling the API.
