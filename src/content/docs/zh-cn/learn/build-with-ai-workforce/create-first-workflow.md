打开**自动化 → 新建 → 自动化任务**，创建独立 Job。定义结果，选择执行员工和输入，先手动运行一次。检查结果后再发布并启用触发规则。Job 的具体操作见[工作流构建器](/zh-cn/automate/workflow-builder/#组合一个-job)。如果工作从交付卡片开始，可参考[看板模板演练](/zh-cn/getting-started/first-automation/)。
