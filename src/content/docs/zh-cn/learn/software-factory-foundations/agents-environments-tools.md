**智能体**（工作空间里常以数字员工呈现）执行步骤。**工具**与 **MCP** 服务暴露操作。**环境**是执行发生的地方：仓库、设备与流水线。

配置 MCP 或连接仓库，本身并不等于运行时已授权。从[智能体](/zh-cn/user-guide/ai-employees/)开始，再看[环境](/zh-cn/software-factory/environments/)与[工具与 MCP](/zh-cn/build/mcp-integration/)。
