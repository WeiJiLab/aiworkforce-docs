工作流描述一类工作怎样完成，自动化决定何时启动，员工执行被分配的步骤，一次运行记录一次实际执行。

## 区分方法与本次尝试

处理表单校验请求的可复用方法可以是：阅读请求、识别受影响的行为、提出或实施限定范围的修改，再收集所需检查结果。今天这条 Issue 提供的是具体表单和预期提示。

手动操作或已配置的规则用这些输入启动一次运行。后续触发会产生另一运行。同一方法可以复用，但每次的输入、输出和结果可能不同。
