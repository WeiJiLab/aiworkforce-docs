最快看到价值的方式，是在已配置的交付看板上处理一条小 Issue。

1. 确认范围与验收标准。
2. 在看板上跟进实现。
3. 把验证证据对照每条验收标准。
4. 记录审阅决定。

动手路径见[快速开始](/zh-cn/getting-started/quickstart/)，完整示例见 [Issue 到 PR](/zh-cn/recipes/issue-to-pr/)。
