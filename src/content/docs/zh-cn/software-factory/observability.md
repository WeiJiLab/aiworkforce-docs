这里的可观测性是指你能找到一张卡片、一段会话或一次运行发生了什么。当前产品把这些记录留在工作台、会话历史、自动化运行历史和管理员监控视图里。它不额外提供单独的追踪后端、软件工厂指标产品，或一份由本文档配置的日志导出。

## 去哪里看

| 问题                               | 打开                                           |
| ---------------------------------- | ---------------------------------------------- |
| 员工在对话里做了什么？             | 会话及其工具活动                               |
| Job 运行了、失败了，还是被取消了？ | 运行历史，包括状态、输出、错误和时间戳         |
| 收集是否保存了 Issue？             | 服务端回执，不是聊天摘要                       |
| 批次是否通过、合并或发布？         | 卡片和批次上的泳道记录                         |
| 部署是否有容量压力？               | [用量与分析](/zh-cn/administration/analytics/) |

哪条记录支持哪项结论，见[证据与追踪](/zh-cn/software-factory/evidence/)。监控图表不会告诉你员工的回答是否可以接受。

## 当记录缺失

缺失的运行意味着你不能声称 Job 执行过。重试前检查 Job、触发规则和授权。持久执行系统可以恢复它知道是安全的簿记和步骤。它不会假设重放一次不透明的 Agent 调用是无害的。对于外部写入，先查看已有输出。见[运行与恢复](/zh-cn/automate/runs-recovery/)。

能读取该运行的调用方可以通过 `GET /api/automation/v1/runs/{run_id}/audit` 查看自动化运行的审计。这个视图不是完整的合规档案。见[审计与合规](/zh-cn/operate/audit/)。
