会话连接你的请求、员工执行和生成文件。发出任务后，通过会话状态、执行计划和工具活动了解已经完成了哪些步骤，以及员工是否需要你的输入。

## 查看会话状态

界面区分工作中、待处理、失败和中断等状态。对话空闲不代表业务需求都已满足。自动化或委派会话可能以执行记录形式呈现，而不是允许继续输入的普通对话。

## 选择执行边界

所选运行时支持时，输入区域提供以下权限模式：

| 模式         | 预期行为                                   |
| ------------ | ------------------------------------------ |
| 默认权限     | 遇到需要授权的操作时询问。                 |
| 自动接受编辑 | 自动接受文件编辑，其他操作仍可能要求确认。 |
| 计划模式     | 制定方案，不直接修改文件。                 |
| 跳过确认     | 在运行时已获权限内自动执行操作。           |

发送前检查当前模式。产品可以保留会话设置，不应根据另一段对话推断当前权限。连接设备后，命令以本机操作系统用户执行；工作目录不是操作系统沙箱，此时使用设备授权规则，而不是云端权限选择器。

## 查看计划与工具动作

运行时上报计划后，界面才出现**查看执行计划**入口。打开后检查待执行、进行中、完成或失败的步骤。不是每次回答都有计划，步骤完成也只是进度信号，并不等于独立验证。

出现授权请求时，先阅读工具名称和输入预览，再允许或拒绝。只读会话或已过期交互不能在原位置继续回应。见[人工确认](/zh-cn/user-guide/human-approval/)。需要检查底层事件顺序或工具返回时，可以使用会话的 Debug 模式。

## 在工作台核对执行记录

Security Review、Code Review 和 Test Evidence 显示的是已保存的应用上下文。查看审查发现时，确认文件位置来自当前 PR 快照；切换测试运行时，确认报告编号和修订版本一起变化。工作台中的“员工已就绪”只表示应用可以调用员工，不表示权限检查或测试已经通过。

## 清空会话

使用云端执行的可编辑主智能体会话在输入区提供**清空上下文**。它会重置消息与模型上下文，取消当前回合，并清除尚未处理的排队消息。工作空间文件和已有工单会保留。

工作完成后，继续[审阅结果与产物](/zh-cn/user-guide/artifacts-evidence/)。遇到执行问题，见[问题排查](/zh-cn/resources/troubleshooting/)。
