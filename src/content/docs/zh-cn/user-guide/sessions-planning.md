会话连接你的请求、员工执行和生成文件。围绕一个清晰目标组织会话，通过计划、工具活动和产物检查工作。

## 开始与继续会话

在目标工作空间中选择已就绪员工，说明目标、相关文件或原文、验收标准，以及允许执行哪些操作。继续完善同一目标时沿用原会话，通过员工的历史会话返回之前的工作；需要经常查看的会话可以置顶。

界面区分工作中、待处理、失败和中断等状态。对话空闲不代表业务需求都已满足。自动化或委派会话可能以执行记录形式呈现，而不是允许继续输入的普通对话。

## 选择执行边界

所选运行时支持时，输入区域提供以下权限模式：

| 模式         | 预期行为                                   |
| ------------ | ------------------------------------------ |
| 默认权限     | 遇到需要授权的操作时询问。                 |
| 自动接受编辑 | 自动接受文件编辑，其他操作仍可能要求确认。 |
| 计划模式     | 制定方案，不直接修改文件。                 |
| 跳过确认     | 在运行时已获权限内自动执行操作。           |

发送前检查当前模式。产品可以保留会话设置，不应根据另一段对话推断当前权限。连接设备后，命令以本机操作系统用户执行；工作目录不是操作系统沙箱，此时使用设备授权规则，而不是云端权限选择器。

## 查看计划与工具动作

运行时上报计划后，界面才出现**查看执行计划**入口。打开后检查待执行、进行中、完成或失败的步骤。不是每次回答都有计划，步骤完成也只是进度信号，并不等于独立验证。

出现授权请求时，先阅读工具名称和输入预览，再允许或拒绝。只读会话或已过期交互不能在原位置继续回应。需要检查底层事件顺序或工具返回时，可以使用会话的 Debug 模式。

## 审阅与清空

打开生成文件，按验收标准核对变化。在同一会话中提出具体修改要求，说明哪项结果需要调整，以及应补充什么证据。

清空对话会重置消息和模型上下文，取消当前执行回合及尚未处理的排队消息。它不会还原工作空间文件，也不会删除已有工单。操作前阅读确认说明。
