在主导航打开**工作台**（地址是 `/automations?tab=board-flow`），选择受影响的看板。打开卡片，查看当前泳道、泳道内的步骤，以及最近一次执行或待处理的请求。如果卡片属于共享测试或发布批次，先核对批次内的其他卡片，再操作批次。

| 看到的情况           | 怎么处理                                                                                                                           | 怎么确认已恢复                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 草稿等待确认         | 在卡片上澄清变更范围、验收标准和允许修改的仓库。信息齐备后，回应待处理的确认请求。                                                 | 在卡片上找到已确认的范围。开发开始后，打开关联会话跟进。                   |
| 员工提问或请求审批   | 打开卡片上的请求，回复决定及其适用范围。                                                                                           | 在关联会话里核对回复和下一步执行。                                         |
| 员工无法访问所需仓库 | 确认项目使用的是目标工作空间中已启用的仓库连接，再单独核对执行员工的仓库授权。修正授权后，从卡片恢复执行。                         | 确认关联执行能访问目标仓库和版本。                                         |
| 卡片已被人工接管     | 记录人工完成的工作，可以继续自动推进时，明确交还卡片。                                                                             | 核对接管已结束，工作流可以继续推进。恢复暂停的工作流后，接管状态仍然有效。 |
| 编排已暂停           | 打开该泳道的编排，处理编辑器提示的映射或配置问题，保存后恢复。                                                                     | 查看下一个可执行步骤和对应记录，确认卡片是否推进。                         |
| 必需测试失败         | 阅读失败记录，确认受测版本和环境，并检查是否已有修复在进行。在配置的泳道退回受影响的工作，附上失败的验收项和证据。                 | 验证修订后的提交或候选版本，并将新结果关联到卡片。                         |
| 缺少测试结果         | 核对配置的流水线是否为这个候选版本执行过，以及该卡片是否属于对应批次。如果流水线未能执行，记录实际情况并附上确实执行过的人工检查。 | 检查记录应包含受测版本、环境和结果。保留未验证的检查项供审阅。             |

如果采集需求的 Job 在创建或更新工作项之前失败，先看[运行、结果与恢复](/zh-cn/automate/runs-recovery/)。遇到配置问题，参见[配置交付看板](/zh-cn/getting-started/first-software-factory/)、[代码仓库](/zh-cn/integrations/code-repositories/)或 [CI/CD 集成](/zh-cn/software-factory/cicd/)。

恢复后，打开关联会话并核对卡片的最新步骤。如果变更经过修订，按[证据与追踪](/zh-cn/software-factory/evidence/)和[质量门禁](/zh-cn/software-factory/quality-gates/)确认哪些检查和决定适用于新版本。
