一个 **Agent 包**定义可复用的岗位和工作方法。通过测试的版本可以发布为模板，供团队在工作空间创建数字员工。

## 定义 Agent

写清 Agent 要交付什么、需要哪些输入，以及何时应交回人工。研究助手的完整示例见 [Agent 定义](/zh-cn/build/employee-definition/)。

| 文件                         | 配置内容                                                |
| ---------------------------- | ------------------------------------------------------- |
| `.aiworkforce/employee.yaml` | 岗位职责、输入、输出、约束和入口 Skill（`entry_skill`） |
| `.aiworkforce/router.md`     | 如何调用入口 Skill，怎样处理输入缺失和超出范围的请求    |
| `skills/<skill-id>/SKILL.md` | 任务的执行方法、检查步骤和输出格式                      |
| `.claude-plugin/plugin.json` | Plugin 的标识、版本和说明                               |

会话和仓库中的指令写在哪一层，见 [Agent 指令](/zh-cn/build/prompts-rules/)。
