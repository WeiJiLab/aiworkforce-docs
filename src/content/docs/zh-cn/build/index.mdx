先定义数字员工的岗位，再用[数字员工构建器](/zh-cn/build/builder/)创建并校验员工包。把员工包发布为模板后，其他人就可以在工作空间中安装它。从模板安装数字员工的步骤见[智能体与数字员工](/zh-cn/user-guide/ai-employees/)。

在控制台顶栏打开 **FDE 工作台**。路径是 `/fde/`。既不是 FDE 用户也不是管理员的登录用户会看到权限说明。**渠道配置**和 **Agent 评估**只对管理员显示。
