当软件工厂中的一项任务需要新的 Agent 能力时，先明确它要交付什么，再选择 Skill、Plugin 或 Tool 来实现。需要多个 Agent 配合时，定义好任务如何交接。用真实场景验证 **Agent 包**中的能力，再将它发布为模板，供团队安装。

已有合适的模板？直接[在工作空间安装数字员工](/zh-cn/getting-started/first-employee/)。要通过 API 或 SDK 接入自己的应用，请看 [Developer](/zh-cn/developer/)。
