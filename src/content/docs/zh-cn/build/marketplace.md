由系统管理员打开**管理控制台 → 数字员工市场**，配置共享市场的仓库地址和 Git Token。

先在这一页初始化构建器，[Agent 构建器](/zh-cn/build/builder/)才能打开会话。这一页不编辑 Plugin。Agent 包内容留在构建器里，可转换的插件列在[标准数字员工市场](/zh-cn/build/market/)。

Token 是凭据。不要把它写进员工指令、Skill 或会议记录。
