本表定义业务用户、构建者和开发者共享的产品词汇。技术标识符以英文为准，中文说明使用自然的产品表达，并保持相同技术含义。

## 常用术语

| English             | 简体中文     | 含义                                   |
| ------------------- | ------------ | -------------------------------------- |
| Workspace           | 工作空间     | 组织员工、资源与协作的共享上下文。     |
| AI employee         | 数字员工     | 承担明确职责的已配置工作者。           |
| Employee template   | 员工模板     | 已发布、可用于创建员工的可复用能力。   |
| Employee definition | 员工定义     | 职责、输入、输出及能力需求的描述。     |
| Agent               | 智能体       | 根据上下文指执行参与者或某项能力。     |
| Skill               | 技能         | 描述任务执行方法的指令。               |
| Plugin              | 插件         | 可复用能力的分发包。                   |
| Tool                | 工具         | 执行中的智能体可调用的操作。           |
| MCP server          | MCP 服务     | 使用模型上下文协议提供外部工具的服务。 |
| Session             | 会话         | 对话及相关执行上下文。                 |
| Task inbox          | 任务收件箱   | 审阅进入空间的请求的界面。             |
| Issue               | 事项 / Issue | 有独立来源和审核状态的请求。           |
| Automation          | 自动化       | 描述重复工作与触发配置的定义。         |
| Run                 | 运行         | 自动化或工作流程的一次执行。           |
| Artifact            | 产物         | 可以检查的生成或修改输出。             |
| Evidence            | 证据         | 支持判断或审核决定的信息。             |
| Delivery workbench  | 交付工作台   | 协调软件交付的产品界面。               |
| Delivery card       | 交付卡片     | 在已配置看板中推进的工作记录。         |
| Human review        | 人工审核     | 人对工作的检查与决定。                 |

## 结合上下文理解

员工模板与工作空间员工不同：发布模板让能力可以被选择，创建员工则在工作空间中初始化具体工作者。

会话、收件箱事项和自动化运行也不同。一次运行可以收集一条事项，但事项可能仍然等待审核；会话生成了产物，也不能直接证明关联请求已经解决。

指输出本身时使用**产物**，指支持结论的信息时使用**证据**。例如报告是产物，报告中的来源摘录可以提供证据。

## 写作与翻译

代码中的技术标识符、字段名和路径保持原样。解释文字、标签和任务背景可以自然翻译，但不能改变实际行为。页面交叉引用优先使用本表术语，帮助读者在不同学习路径间切换。
