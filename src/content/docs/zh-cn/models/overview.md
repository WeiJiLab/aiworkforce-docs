会话可用模型取决于员工、运行时内核和已配置渠道。应从产品提供的模型列表中选择，而不是假定填写任意供应商模型名称都能使用。

## 为任务选择模型

打开已就绪员工的会话，在输入区域检查**模型**。从可用选项中选择。已保存的模型当前不可用时，界面会标明；请管理员核对员工的运行时与渠道配置。

模型与运行时支持时，可以通过**思考等级**调整推理投入。界面提供默认，以及低、中、高、超高、最大等等级。具体支持范围由模型和运行时决定。更充分思考可能更慢，也不保证结果一定更好。

评估变化时，使用相同任务、输入、工具和验收标准，同时检查正确性、耗时与已记录用量。如果提示词、权限或上下文也发生变化，就不能把差异全部归因于模型。

## 区分三种度量

| 度量               | 含义                                             |
| ------------------ | ------------------------------------------------ |
| 已记录 Token 用量  | 会话结果提供的用量字段；数据缺失时明确保留空缺。 |
| 上报费用（未核账） | 运行时上报金额，尚未与供应商账单核销。           |
| 官方参考估算       | 按平台计价目录中的适用条件和已知用量计算的金额。 |

参考估算不会直接扣款，也不会替换运行时原始费用记录。模型、发生时间、计量项、地区、渠道或服务档位缺少已核实价格时，总额可能不完整。

## 计价边界

目录使用精确模型标识符及已配置别名，按生效价格版本和独立计量项计算。输入、输出、缓存读取和缓存写入可能采用不同费率。上下文长度分档基于单次请求，而不是整项任务累计输入量。

未知或已过期价格不能解释为免费。部分估算仅代表已计价部分。供应商发票、税费、工具费和合同调整，需要各自经过核实的信息；平台不会自动对供应商发票核账。

本文不提供固定价格表。使用估算做规划前，管理员应核对供应商当前条款，以及目录中配置的价格适用条件。
