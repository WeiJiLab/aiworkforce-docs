员工可以使用已配置 MCP 服务提供的工具。需要在产品中选择或检查已有连接时，按本文操作。在员工包中声明依赖的构建者应阅读 [MCP 服务](/zh-cn/build/mcp-integration/)。配置协议端点的操作者应阅读 [MCP 集成](/zh-cn/integrations/mcp/)。

## 选择所需能力

从「集成」浏览 MCP 目录，或在创建员工时查看可用工具。已发布模板可能已包含 MCP 服务，也可以在创建流程中选择额外可用服务。平台飞书 MCP 使用其托管连接与授权流程，不要向该托管服务写入自定义凭据。

## 验证员工实例

1. 在工作空间中打开员工档案。
2. 进入「方法与能力」，刷新清单。
3. 找到 MCP 条目，检查安装状态、来源及已发现的工具。
4. 在提供检查入口时检查连接；如果提示需要授权，完成相应授权。
5. 新建会话，对该账号允许访问的资源尝试一次小范围读取。

档案区分「已配置」和「已安装」，也区分「尚未确认」和「连接正常」。检查缺失或过期不会一概阻止接单；应根据任务真正需要的能力查看诊断信息。

## 排查缺失的工具

工具没有出现时，先检查预期的模板或插件配置是否真正应用到了员工。需要授权时，完成或重新连接外部账号。目录中有该服务、连接检查成功，都不代表可以访问外部账号下的全部资源，还应核对账号权限。

给员工分配会写入其他系统的任务前，先尝试一次小范围读取，保留会话和工具结果，以说明成功或失败的环节。配置本身需要修正时，将服务名称和错误上下文交给模板维护者。
