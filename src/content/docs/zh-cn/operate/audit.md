审计回答谁调用了一项工作，以及平台为这次调用存了什么。当前契约是自动化运行审计视图 `GET /api/automation/v1/runs/{run_id}/audit`，调用方需要能够读取该运行。会话历史、交付卡片上的决定和管理员监控是分开的记录。它们合在一起也不是合规产品、保留策略，或一份自行满足某项法规的导出。

## 你可以读到什么

运行响应包含状态、输出、摘要、错误和生命周期时间戳。审计视图是授权调用方对该运行的读取。取消是另一次调用，并且只是请求停止。能够阅读会话历史的工作空间角色，不会授予一般的项目文件访问权或这个 API 范围。

把记录放在它支持的结论旁边。运行审计显示的是 Job 调用。交付卡片显示人工决定和代码引用。监控图显示容量。它们的对应关系见[证据与追踪](/zh-cn/software-factory/evidence/)。[用量与分析](/zh-cn/administration/analytics/)不是审计日志。

## 必须自己记录的事

撤销员工授权会改变之后的检查，但不能证明正在进行的进程已经停止。删除平台凭据不会撤销上游令牌。收回访问时把这两个动作都记下来。本文档没有描述这些管理员操作的不可变档案。

不要把密钥、客户内容或私有地址复制进审计备注或本文档站点。令牌放在调用方的密钥库里。如果某项控制要求保留期限或特定报告，把它当作部署义务，而不是审计端点的功能。
