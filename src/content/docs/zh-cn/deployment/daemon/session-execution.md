为你有权执行的 Claude Code 员工新建会话。在**执行位置**选择你拥有且支持 `device_rpc` 的在线电脑。如果列表提示**需更新客户端**，请先更新设备客户端。普通会话必须在发送第一条消息前选择。见[我的机器](/zh-cn/deployment/daemon/my-machines/)。

如果希望 AI Workforce 从已配对的电脑中选机，可以在普通 Claude Code 会话发送首条消息前选择[执行池](/zh-cn/deployment/daemon/execution-pools/)。

## 核对执行目录和权限

会话中的工具命令以这台电脑上的操作系统用户身份运行。配对时指定的 `--workspace` 是命令的起始目录，进程能访问哪些文件取决于该用户的系统权限。个人设备上的工具只能由会话所有者调用，调用还须符合工作空间权限和会话的工具授权。

## 更换执行位置

普通会话开始执行后就会锁定位置。需要更换位置时，请新建普通会话。符合条件且处于空闲状态的自动化会话，其所有者可以在回合之间切换位置。下一轮使用新选位置，切回时可继续该位置的运行上下文。设备离线或被撤销时，会话仍绑定该设备，直到切换或新建会话。默认设备设置用于在选择器中标记偏好。
