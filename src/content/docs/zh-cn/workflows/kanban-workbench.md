看板自动化工作台从主导航的**工作台**进入，地址是 `/automations?tab=board-flow`。它把看板变成一条持续运行的软件交付工作流。这是同一条软件工厂路径，以卡片、泳道和批次的形式被观察。它不是通用看板产品，也不是第二套引擎。

## 它是什么

**卡片**是工作项。**泳道**是带有内置或自定义行为的列。卡片上的**步骤**是执行状态。**运行**是完成这项工作的会话或编排节点。**产物**是产出的变更或文件。**证据**是与卡片放在一起的会话、代码引用、测试记录和人工决定。

看板是工作管理界面。工作流是泳道规则。自动化启动并继续这项工作。员工负责执行。

## 何时使用

当多项工程工作必须经过相同泳道、有时还要组成批次，并且每一项都需要可追溯的运行和验收证据时，使用看板。工作只是一个有边界的任务、不应变成交付卡片时，使用单个[自动化 Job](/zh-cn/automate/fundamentals/)。

## 如何工作

内置泳道：

```text
需求 → 开发 → 测试发布 → 测试验证 → 生产发布 → 已完成
```

| 泳道     | 编号    | 什么推动卡片                     | 粒度                   |
| -------- | ------- | -------------------------------- | ---------------------- |
| 需求     | DRAFT   | 人澄清范围，直到卡片就绪         | 逐卡                   |
| 开发     | DEV     | 泳道员工在会话中编码             | 逐卡                   |
| 测试发布 | PREPARE | 就绪卡片加入候选批次             | 整批                   |
| 测试验证 | TEST    | 测试运行并记录通过或失败         | 逐卡，位于发布批次之内 |
| 生产发布 | RELEASE | 集成存在时合并、等待、部署并核对 | 整批                   |
| 已完成   | DONE    | 批次收尾                         | 整批                   |

泳道内部的步骤可以是澄清、就绪、编码、运行中、通过、失败、合并、部署、核对，或等待人。这个步骤就是工作流状态。只改标签而没有运行，并不等于做完了工作。

可以添加自定义泳道。自定义泳道不继承需求或开发的行为。看板模板和泳道编排决定那里发生什么。

没有在制品上限。并行是多张卡片，再加上为测试和发布把卡片组成的批次。本版本的依赖是批次成员关系，不是通用依赖图。

## 如何配置

1. 创建工作台项目和看板。连接仓库，以及测试或发布泳道要调用的流水线。卡片不会创建这些资源。
2. 把就绪的员工放到泳道上。授权这些员工修改他们可以改的仓库。工作空间里的仓库连接并不是这项授权。
3. 从自动化页面打开**编排**，选择工作空间、看板和泳道。只有泳道需要多个执行器时才把它们串起来。单个执行器仍然是带自己日程的 Job。
4. 开发之前确认草稿。需求泳道用来固定范围、验收标准和允许的仓库。确认需求不会同时批准修改仓库，也不会授予凭据。
5. 查看卡片的会话、测试记录和决定。接管会停止自动推进。需要继续时明确交还。只恢复暂停并不能清除接管。

泳道上的代码执行器是具名的平台能力，例如测试准入、发布推进和批次移动。它们不是配置里的任意代码。

## 一张实际的卡片

触发：人把卡片标为就绪后，卡片进入开发。上下文：已确认的需求和已授权的仓库。智能体：开发泳道的员工，为这张卡片新建会话。步骤：编码，然后进入测试发布、测试验证和生产发布的批次。验证：测试记录，以及与验收标准的比较。输出：会话、代码引用或 Pull Request，以及决定。人介入的位置：确认草稿、回答卡片、测试失败后退回，以及发布决定。

批次关闭不能证明生产发布已经完成。只有仓库和流水线集成存在时，合并和生产才会执行。

## 卡片被挡住时

| 状态         | 怎么处理                                             |
| ------------ | ---------------------------------------------------- |
| 等待人       | 回答卡片。运行可以处于等待人工，并且不占用执行名额。 |
| 测试失败     | 阅读测试记录并退回工作。不要改列名就当作已经修复。   |
| 已被接管     | 在你明确交还之前，自动推进保持停止。                 |
| 缺少仓库授权 | 授权泳道员工。把提示词写长并不会增加授权。           |
| 编排已暂停   | 按编辑器报告修复映射，保存后再恢复。                 |

## 限制

看板不按在制品上限、优先级数字，或一套手工维护的「待办到完成」列名来调度。使用上面的泳道，或你配置的自定义泳道。按卡片准备的沙箱、预览浏览器和无人值守发布都不在本版本中。
