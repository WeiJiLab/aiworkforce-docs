本页汇集构建者或平台工程师从产品界面之外访问 AI Workforce 的接口。编写员工仍在[构建数字员工](/zh-cn/build/architecture/)。仓库等产品连接仍在[集成](/zh-cn/integrations/overview/)。

## 选择接口

| 需要                      | 从这里开始                                        |
| ------------------------- | ------------------------------------------------- |
| 通过 HTTP 调用平台        | [REST API](/zh-cn/developer/api-reference/)       |
| 为人或机器做认证          | [认证](/zh-cn/developer/authentication/)          |
| 查看已部署的 schema       | [OpenAPI 参考](/zh-cn/integrations/openapi/)      |
| 让 Agent 调用已注册的 Job | [MCP 集成](/zh-cn/integrations/mcp/)              |
| 配对一台执行计算机        | [CLI](/zh-cn/integrations/cli/)                   |
| 构建应用客户端            | [SDK](/zh-cn/integrations/sdk/)                   |
| 了解尚未提供的能力        | [Agent 协议](/zh-cn/integrations/agent-protocol/) |

[接口对照](/zh-cn/developer/cli-sdk/)比较这些选择，并写明当前限制：没有受支持的通用 Python 或 TypeScript SDK 包，也没有捆绑的 ACP 或 A2A 服务。

## 验证一条工作流

1. 约定结果、允许的资源和验收标准。工作仍不清楚时，使用[实践手册](/zh-cn/learn/)。
2. 只调用凭据被允许使用的端点或工具。密钥留在调用方的密钥库中。
3. 试一次正常调用、一次缺失输入和一次被拒绝的资源。阅读运行 ID 和错误。不要把 HTTP 202 当成业务结果已经完成。
4. 当能力是一名员工时，校验员工包，并用预期的运行时作为工作空间实例试一次。

[平台架构](/zh-cn/developer/architecture/)说明会话、Job 和交付记录有何不同。[贡献](/zh-cn/developer/contributing/)面向本文档和产品源码的修改，不是面向调用 API。
