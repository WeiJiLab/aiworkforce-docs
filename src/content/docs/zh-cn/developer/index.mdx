想改变运行产物的展示方式？从 Viewer App 入手，给文件预览添加一个视图。

可用接口包括 HTTP 管理与 Automation 路由、入站 Webhook、Automation MCP 和设备执行 CLI。通过入站 Webhook 触发已发布的 Job 后，查询对应的运行即可获取结果。当前未发布通用 SDK 包，也未提供 ACP 或 A2A 服务。
