在会话里打开产物时，平台会根据内容、识别出的格式和当前查看模式匹配 Viewer App。如果有多个匹配项，可以在「产物查看器」菜单切换。例如，打开 `dashboard.html` 时，用「HTML 预览」看报告的页面布局，切到「源码与差异」就能读生成这份报告的 HTML。

## 文档与数据

| 查看器    | 适合打开                              | 能看到什么                                                               |
| --------- | ------------------------------------- | ------------------------------------------------------------------------ |
| Markdown  | `README.md`、交付说明或 Markdown 报告 | 按标题、列表和代码块阅读排版后的文档。                                   |
| HTML 预览 | `dashboard.html` 等 HTML 报告         | 在隔离的预览区查看页面布局和内嵌样式。脚本、表单和外部资源在预览中禁用。 |
| JSON      | `report.json` 等结构化输出            | 按缩进阅读对象和数组，同时保留原文中的大整数和重复键。                   |

## 图表与规格

| 查看器               | 适合打开                                                           | 能看到什么                                                                                                        |
| -------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| Architecture Diagram | Draw.io、SVG、Graphviz DOT、Mermaid 或 Context Mapper CML 图表文件 | 渲染图表并支持平移和缩放。Context Mapper 图表还可以查看模型细节和调整布局选项。渲染失败时可切回源码检查图表语法。 |
| DOORS ReqIF          | ReqIF 或 ReqIFZ 规格导出                                           | 按模块、章节阅读需求条款、属性和覆盖关系，并预览可用的附件。                                                      |

## 代码与协作

| 查看器       | 适合打开                                        | 能看到什么                                                     |
| ------------ | ----------------------------------------------- | -------------------------------------------------------------- |
| 源码与差异   | 文本文件或有前后两个版本的代码变更              | 查看源码，或在差异模式下逐行比较新增和删除的内容。             |
| Pull Request | PR 快照，或已连接 GitHub 仓库的会话中的 PR 引用 | 在同一视图中阅读 PR 描述、文件变更、提交、检查结果和审阅记录。 |

## API

| 查看器     | 适合打开                              | 能看到什么                                               |
| ---------- | ------------------------------------- | -------------------------------------------------------- |
| Swagger UI | 包含 OpenAPI 定义的 JSON 或 YAML 文件 | 按路径和 HTTP 方法浏览 API，展开操作查看参数和响应定义。 |

要给现有产物增加一种展示方式，可以跟着示例给 JSON 文件添加字节数预览。[开发 Viewer App](/zh-cn/developer/viewer-apps/)
