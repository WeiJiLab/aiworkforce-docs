# 竞品文档分类与内容覆盖

核对日期：2026-11-17。本文用于文档信息架构与内容规划，不是功能对标承诺。竞品网站会更新，以本次读取的官方导航和索引为依据。相似的学习主题可以共用入口，但不能据此推断 API、客户端、部署模式或权限模型相同。

## 核对依据与映射约定

- Cursor：[用户提供的 Self-Hosted Machines 页面](https://cursor.com/docs/cloud-agent/self-hosted)、[Markdown 原文](https://cursor.com/docs/cloud-agent/self-hosted.md)、[官方 llms.txt](https://cursor.com/llms.txt)。索引区分 Cursor Documentation、CLI Documentation、API Documentation、Help Center 四个入口，下面保留该层级。
- Augment：[Introduction](https://docs.augmentcode.com/introduction)、[llms.txt](https://docs.augmentcode.com/llms.txt)。读取 Introduction 返回的 `nav.versions`，当前默认版本为 Auggie 1.x；一级分类为 Getting Started、Cosmos、Auggie CLI、Other clients、Admin、Models & Pricing、Troubleshooting。Cosmos 的重要二级分类也单独列出，避免一级总览掩盖内容缺口。
- 8090：[用户提供的 Requirements Writing Guide](https://docs.8090.ai/opinions/requirements-writing-guide)、[Markdown 原文](https://docs.8090.ai/opinions/requirements-writing-guide.md)、[llms.txt](https://docs.8090.ai/llms.txt)。索引明确区分 Docs、Learn、Developers，下面覆盖每个入口和其直接分类。

“对应页面”使用当时实现的文档。“差异”保留真实产品边界，不能把“已经写明能力边界”误解成“已经提供竞品同名功能”。2026-11-18 起，站点改为单一侧栏；下表里的 User guide、Build、Learn 等名称指内容域，不再表示独立入口。当前目录以 [NAVIGATION.md](NAVIGATION.md) 为准。

## 真实能力的依据

本站产品描述以平台基准 `c75d55ab` 的实现为准，重点核对了以下契约，而不是从竞品页面推断功能：

- `frontend/src/features/board-flow-management/model/delivery-lanes.ts`：内置泳道、批次合入后关闭、独立生产发布扫描与资源回收。
- `frontend/src/features/board-flow-management/ui/DeliveryHumanRequestPanel.tsx`：当前需求修订确认、问题答复、批次级影响与交回。
- `frontend/src/features/board-flow-management/ui/DeliveryPrFollowupDialog.tsx`：结束平台跟进不关闭外部 PR，也不自动交回卡片。
- `backend/application/session/automation_collection_prompt.py` 与 `backend/application/automation/automation_durable_run_orchestrator.py`：已配置收集时需要实际服务端回执，无匹配项也需明确完成。
- `frontend/src/features/automation-management/ui/AutomationIssueCollectionFields.tsx`：收件箱与工作台去向、需求员工前提、非开发事项保留及当前运行时要求。
- `backend/domain/orchestration/model/work_order.py`：已有编排工作单、分派和验收字段；不能与交付卡或竞品 Work Orders 混同。
- `backend/application/board_delivery/README.md`：空间代码凭据与执行员工显式授权。

本轮的一级知识域已覆盖三个参考站点中的通用学习主题：入门、使用、构建、自动化、交付、集成、开发、执行环境、安全、团队管理、模型用量、资源与实践方法。剩余差异主要是实际产品边界：没有官方通用平台 SDK/管理 CLI、托管 Git、内置 IDE 客户端、独立 Blueprint/Feedback Theme 模块、企业 SSO 或 Kubernetes/Helm 同等能力承诺。不能为填满竞品目录而把这些差异写成已实现功能。
